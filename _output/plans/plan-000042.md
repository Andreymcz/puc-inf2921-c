## Brief
debug and print llm calls

## Agent Interpretation
Add structured debug logging to both LLM call sites in the project so developers can trace
prompts sent to and responses received from Ollama during a session. Two call sites exist:

- `fala-gavea/src/fala_gavea/pipeline/label_clusters.py` -- raw httpx calls with no logging
  and a silent `except Exception` swallow.
- `gavealab-poc/gavealab_poc/llm.py` -- logs model/URL at INFO but does not log prompt
  content, only message count and char length.

The fix adds a `DEBUG_LLM` env var (`FALA_GAVEA_DEBUG_LLM` / `GAVEALAB_DEBUG_LLM`) that,
when set to `1`, promotes full prompt and response content to `INFO` level so it surfaces
in Streamlit's terminal without requiring Python-wide DEBUG configuration. Normal (non-debug)
runs are unaffected -- only silent error swallowing is fixed unconditionally.

## Scope
- `fala-gavea/src/fala_gavea/pipeline/label_clusters.py`
- `gavealab-poc/gavealab_poc/llm.py`

## Review
Perspectives evaluated: DX (primary), OPS (tangential).
- **DX** -- adopted: structured logging with an opt-in env var keeps dev and prod behaviour
  separate; error messages include cluster ID and exception text for actionable triage.
- **OPS** -- adopted: `DEBUG_LLM=1` prints at INFO so no log-level reconfiguration is needed
  in Streamlit dev sessions. Flag is intentionally not enabled by default to avoid log noise
  in course demo runs.

## Steps

### Step 1 -- Add logging to `label_clusters.py`
**File:** `fala-gavea/src/fala_gavea/pipeline/label_clusters.py`

Add `import logging` at the top. Add a module-level logger and a `DEBUG_LLM` flag:

```python
import logging
log = logging.getLogger(__name__)
_DEBUG_LLM = os.environ.get("FALA_GAVEA_DEBUG_LLM", "0") == "1"
```

### Step 2 -- Log the LLM request in `label_clusters.py`
**File:** `fala-gavea/src/fala_gavea/pipeline/label_clusters.py`

Inside `label_clusters`, before the `httpx.post` call, add:

```python
log.info("LLM request: model=%s cluster=%d", OLLAMA_MODEL, cid)
if _DEBUG_LLM:
    log.info("[DEBUG_LLM] prompt:\n%s", prompt)
```

### Step 3 -- Log the LLM response and fix the silent except in `label_clusters.py`
**File:** `fala-gavea/src/fala_gavea/pipeline/label_clusters.py`

After parsing the label from `resp.json()`, add:

```python
log.info("LLM response: cluster=%d label=%r", cid, label)
if _DEBUG_LLM:
    log.info("[DEBUG_LLM] raw response: %s", resp.text[:2000])
```

Replace the bare `except Exception:` with:

```python
except Exception as exc:  # noqa: BLE001
    log.warning("LLM call failed for cluster %d: %s", cid, exc)
    label = f"Cluster {cid}"
```

### Step 4 -- Log prompt content in `gavealab-poc/gavealab_poc/llm.py`
**File:** `gavealab-poc/gavealab_poc/llm.py`

Add a `DEBUG_LLM` flag near the existing constants:

```python
_DEBUG_LLM = os.getenv("GAVEALAB_DEBUG_LLM", "0") == "1"
```

In `chat()`, after the existing `log.debug("  [%d] role=...")` loop, add:

```python
if _DEBUG_LLM:
    for i, m in enumerate(messages):
        log.info("[DEBUG_LLM] msg[%d] role=%s:\n%s", i, m["role"], m.get("content", "")[:2000])
```

And after the `content = response.choices[0].message.content` line, add:

```python
if _DEBUG_LLM:
    log.info("[DEBUG_LLM] response:\n%s", content[:2000])
```

### Step 5 -- Manual smoke test
Run the Fala Gavea Streamlit app and trigger cluster generation with `FALA_GAVEA_DEBUG_LLM=1`
set in the terminal. Verify that:
- INFO lines like `LLM request: model=... cluster=...` appear in the terminal for each cluster.
- `[DEBUG_LLM] prompt:` lines show the full prompt content.
- `[DEBUG_LLM] raw response:` lines show the Ollama response.
- Without the env var set, none of the `[DEBUG_LLM]` lines appear.
