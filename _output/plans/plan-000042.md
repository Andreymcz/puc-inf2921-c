## Brief
debug and print llm calls

## Agent Interpretation
Add structured debug logging to both LLM call sites in the project so developers can trace
prompts sent to and responses received from Ollama during a session. Two call sites exist:

- `fala-gavea/src/fala_gavea/pipeline/label_clusters.py` -- raw httpx calls with no logging
  and a silent `except Exception` swallow.
- `gavealab-poc/gavealab_poc/llm.py` -- logs model/URL at INFO but does not log prompt
  content, only message count and char length.

The fix adds a `DEBUG_LLM` env var (`FALA_GAVEA_DEBUG_LLM` / `GAVEALAB_DEBUG_LLM`) that,
when set to `1`, promotes full prompt and response content to `INFO` level so it surfaces
in Streamlit's terminal without requiring Python-wide DEBUG configuration. Normal (non-debug)
runs are unaffected -- only silent error swallowing is fixed unconditionally.

## Scope
- `fala-gavea/src/fala_gavea/pipeline/label_clusters.py`
- `gavealab-poc/gavealab_poc/llm.py`

## Review
Perspectives evaluated: DX (primary), OPS (tangential).
- **DX** -- adopted: structured logging with an opt-in env var keeps dev and prod behaviour
  separate; error messages include cluster ID and exception text for actionable triage.
- **OPS** -- adopted: `DEBUG_LLM=1` prints at INFO so no log-level reconfiguration is needed
  in Streamlit dev sessions. Flag is intentionally not enabled by default to avoid log noise
  in course demo runs.

## Amendment — 2026-06-15 | On-demand per-cluster AI label generation

**Brief:** Only generate labels with AI if the user clicks a button in the clusters page. Each cluster expander shows its comments; the user clicks "Gerar label com IA" per cluster to trigger label generation for that cluster only.

**Scope added:**
- `fala-gavea/app_pages/clusters.py`

**Context:**
Currently, when the user clicks "🔄 Gerar Clusters", the app automatically calls `label_clusters(df)` for all clusters before displaying anything. This triggers one LLM call per cluster — potentially slow and unnecessary if the user only cares about a subset. The new behaviour:

1. After clustering, set `cluster_label` to a default placeholder (`"Cluster N"`) — no LLM calls.
2. Each cluster expander shows its posts table plus a per-cluster "🤖 Gerar label com IA" button.
3. Clicking that button calls `label_clusters` for that single cluster and updates `st.session_state.cluster_df` in-place so the Plotly chart and expander title reflect the new label on rerun.

### Step 7 — Add per-cluster "Gerar label com IA" button in expanders

**File:** `fala-gavea/app_pages/clusters.py`

Replace the existing per-cluster expander loop:
```python
        for _, row in ordered.iterrows():
            label = row["cluster_label"]
            n = row["n"]
            cluster_posts = df[df["cluster_label"] == label][["text", "territory_name"]].copy()
            cluster_posts.columns = ["Relato", "Territorio"]
            with st.expander(f"{label}  ({n} posts)", expanded=False):
                st.dataframe(cluster_posts, use_container_width=True)
```

With the following updated loop that adds a per-cluster AI label button:
```python
        for _, row in ordered.iterrows():
            label = row["cluster_label"]
            n = row["n"]
            mask = df["cluster_label"] == label
            cluster_posts = df[mask][["text", "territory_name"]].copy()
            cluster_posts.columns = ["Relato", "Territorio"]
            with st.expander(f"{label}  ({n} posts)", expanded=False):
                st.dataframe(cluster_posts, use_container_width=True)
                # Only offer AI labeling for real clusters (not noise)
                cluster_ids_in_group = df[mask]["cluster_id"].unique()
                if not any(cid == -1 for cid in cluster_ids_in_group):
                    if st.button(f"🤖 Gerar label com IA", key=f"label_btn_{label}"):
                        cid = int(cluster_ids_in_group[0])
                        with st.spinner(f"Gerando label para Cluster {cid}..."):
                            new_labels = label_clusters(df[df["cluster_id"] == cid])
                        new_label = new_labels.get(cid, label)
                        st.session_state.cluster_df.loc[
                            st.session_state.cluster_df["cluster_id"] == cid, "cluster_label"
                        ] = new_label
                        st.rerun()
```
