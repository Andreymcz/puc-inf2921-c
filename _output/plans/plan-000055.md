## Brief

Integrar dataset de iluminação pública disponível em ArcGIS (item `5322126ff10e46249be878ddfd057cc5`) com o fala-gavea-segurança. O objetivo é adicionar uma página de mapa que sobreponha os pontos de iluminação da cidade com os posts de cidadãos, permitindo visualizar correlação entre cobertura de iluminação e relatos de segurança por território.

## Context

O app fala-gavea hoje tem seis páginas (Postagens, Nova Postagem, Validar Labels, Dashboard, Explorar Clusters, Inserção em Massa). Posts têm `territory_name` (string) e `territory_level`, mas **não têm coordenadas geográficas lat/lon**. O dataset de iluminação pública da Prefeitura do Rio é um shapefile/GeoJSON com pontos lat/lon de luminárias.

A integração deve:
1. Carregar o dataset de iluminação via ArcGIS Hub Open Data API (download GeoJSON) e cachear localmente.
2. Adicionar uma nova página "Mapa de Iluminação" com mapa Folium que exiba os pontos de iluminação.
3. Sobrepor no mapa os posts (por território, usando coordenadas aproximadas dos bairros) com marcadores coloridos por cluster ou por número de relatos.
4. Exibir métricas de densidade de iluminação por bairro no Dashboard.

**Dataset source**: https://opendata.arcgis.com/api/v3/datasets/5322126ff10e46249be878ddfd057cc5/downloads/data?format=geojson&spatialRefId=4326

**Dependências novas**: `folium>=0.18`, `streamlit-folium>=0.22`

**Sem coordenadas nos posts**: os posts têm apenas `territory_name`. A sobreposição será feita via centróides de bairro (dicionário estático de lat/lon por nome de bairro da Zona Sul do Rio de Janeiro).

### Step 2: Criar módulo de carregamento do dataset de iluminação

Criar `fala-gavea/src/fala_gavea/pipeline/iluminacao.py` com:

```python
"""Carregamento e cache do dataset de iluminação pública (ArcGIS Hub)."""
from __future__ import annotations

import json
import logging
from functools import lru_cache
from pathlib import Path

import httpx
import pandas as pd

ARCGIS_GEOJSON_URL = (
    "https://opendata.arcgis.com/api/v3/datasets/"
    "5322126ff10e46249be878ddfd057cc5/downloads/data"
    "?format=geojson&spatialRefId=4326"
)
_CACHE_PATH = Path(__file__).parent.parent.parent.parent / "data" / "iluminacao.geojson"

log = logging.getLogger(__name__)


def download_iluminacao(cache_path: Path = _CACHE_PATH) -> None:
    """Baixa o dataset de iluminação pública e salva no cache local."""
    cache_path.parent.mkdir(parents=True, exist_ok=True)
    log.info("Baixando dataset de iluminação de %s ...", ARCGIS_GEOJSON_URL)
    with httpx.stream("GET", ARCGIS_GEOJSON_URL, follow_redirects=True, timeout=60) as r:
        r.raise_for_status()
        with cache_path.open("wb") as f:
            for chunk in r.iter_bytes():
                f.write(chunk)
    log.info("Dataset salvo em %s", cache_path)


@lru_cache(maxsize=1)
def load_iluminacao(cache_path: Path = _CACHE_PATH) -> pd.DataFrame:
    """Carrega o dataset de iluminação pública em DataFrame.

    Colunas retornadas: latitude, longitude + atributos do feature (ex: tipo, potência, bairro).
    Faz download automático se o cache não existir.
    """
    if not cache_path.exists():
        download_iluminacao(cache_path)
    with cache_path.open(encoding="utf-8") as f:
        geojson = json.load(f)
    rows = []
    for feat in geojson.get("features", []):
        props = feat.get("properties") or {}
        geom = feat.get("geometry") or {}
        coords = geom.get("coordinates", [None, None])
        rows.append({**props, "longitude": coords[0], "latitude": coords[1]})
    return pd.DataFrame(rows)
```

```python
from __future__ import annotations
import pandas as pd
import folium
from folium.plugins import FastMarkerCluster
import streamlit as st
from streamlit_folium import st_folium

from fala_gavea.pipeline.iluminacao import download_iluminacao, load_iluminacao
from .shared import api_get

BAIRRO_COORDS: dict[str, tuple[float, float]] = { ... }  # dict completo acima

def render() -> None:
    st.header("💡 Mapa de Iluminação Pública")
    st.caption("Luminárias da Prefeitura do Rio sobrepostas aos relatos de cidadãos por território.")

    # Download / status
    col1, col2 = st.columns([1, 3])
    with col1:
        if st.button("📥 Baixar / Atualizar Dataset"):
            with st.spinner("Baixando dataset de iluminação..."):
                try:
                    download_iluminacao()
                    load_iluminacao.cache_clear()
                    st.success("Dataset atualizado.")
                except Exception as e:
                    st.error(f"Erro: {e}")

    try:
        df_luz = load_iluminacao()
    except Exception as e:
        st.warning(f"Dataset não disponível: {e}. Clique em 'Baixar Dataset'.")
        return

    col2.metric("Luminárias no dataset", len(df_luz))

    # Obter posts
    try:
        posts = api_get("/citizen_posts/", limit=999999)
    except Exception:
        posts = []
    post_df = pd.DataFrame(posts) if posts else pd.DataFrame()

    # Mapa base centrado na Gávea
    m = folium.Map(location=[-22.9764, -43.2297], zoom_start=13, tiles="CartoDB positron")

    # Camada de iluminação
    valid_luz = df_luz.dropna(subset=["latitude", "longitude"])
    coords = valid_luz[["latitude", "longitude"]].values.tolist()
    FastMarkerCluster(coords, name="Luminárias").add_to(m)

    # Camada de posts por bairro
    if not post_df.empty and "territory_name" in post_df.columns:
        counts = post_df.groupby("territory_name").size().reset_index(name="n")
        for _, row in counts.iterrows():
            bairro = row["territory_name"]
            n = int(row["n"])
            if bairro in BAIRRO_COORDS:
                lat, lon = BAIRRO_COORDS[bairro]
                folium.CircleMarker(
                    location=[lat, lon],
                    radius=max(8, min(30, n * 2)),
                    color="#1f77b4",
                    fill=True,
                    fill_opacity=0.7,
                    tooltip=f"{bairro}: {n} relatos",
                ).add_to(m)

    folium.LayerControl().add_to(m)
    st_folium(m, width="100%", height=550, returned_objects=[])
```

## Risks & Mitigations

| Risk | Mitigation |
|---|---|
| Dataset ArcGIS indisponível ou URL mudou | Página exibe aviso amigável; usuário pode fornecer GeoJSON manualmente |
| Dataset muito grande (>100k pontos) → mapa lento | `FastMarkerCluster` agrega pontos; se necessário, subsamplear via `df_luz.sample(10000)` |
| Posts sem `territory_name` mapeável nos centróides | Posts sem match são silenciosamente ignorados na camada de posts |
| Coluna de lat/lon com nome diferente no GeoJSON | `load_iluminacao` usa `geometry.coordinates` diretamente (padrão GeoJSON), não propriedades opcionais |

## Review

**P0 — Correctness**
- `load_iluminacao` usa `lru_cache(maxsize=1)` com `Path` como argumento; `Path` é hashável, sem problema.
- `cache_clear()` é chamado após re-download para invalidar o cache da sessão.
- `FastMarkerCluster` aceita lista de `[lat, lon]` — ordem correta (GeoJSON usa `[lon, lat]` em coordinates, invertido corretamente na leitura).
- Timeout de 60s no download é adequado para datasets de iluminação (~MB).

**P1 — Security**
- URL hardcoded no código (não variável de ambiente): aceitável para dataset público sem autenticação.
- Cache em disco em `fala-gavea/data/` — gitignored para evitar commit de dado derivado.
- Sem injeção de parâmetros externos na URL.

**P2 — Maintainability**
- `BAIRRO_COORDS` como constante modular: fácil de estender com novos bairros.
- Download separado de carregamento: usuário controla quando atualizar dados.
