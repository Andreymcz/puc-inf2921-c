## Brief

Integrar dataset de iluminação pública disponível em ArcGIS (item `5322126ff10e46249be878ddfd057cc5`) com o fala-gavea-segurança. O objetivo é adicionar uma camada de mapa que sobreponha os pontos de iluminação da cidade com os relatos de segurança dos cidadãos, permitindo visualizar correlação entre cobertura de iluminação e relatos por território.

5. Atualizar `static/index.html` para adicionar instrução/botão de atualização do dataset.

### Step 1: Criar módulo de infraestrutura para o dataset de iluminação

Criar `fala-gavea-seguranca/src/fala_gavea_seguranca/infrastructure/iluminacao/__init__.py` (vazio) e `loader.py`:

```python
"""Download e cache local do dataset de iluminação pública (ArcGIS Hub)."""
from __future__ import annotations

import json
import logging
from pathlib import Path

import httpx

ARCGIS_GEOJSON_URL = (
    "https://opendata.arcgis.com/api/v3/datasets/"
    "5322126ff10e46249be878ddfd057cc5/downloads/data"
    "?format=geojson&spatialRefId=4326"
)
_DEFAULT_CACHE = Path(__file__).parent.parent.parent.parent.parent / "data" / "iluminacao.geojson"

log = logging.getLogger(__name__)


def download_iluminacao(cache_path: Path = _DEFAULT_CACHE) -> None:
    """Baixa o GeoJSON de iluminação pública e salva no cache local."""
    cache_path.parent.mkdir(parents=True, exist_ok=True)
    log.info("Baixando dataset de iluminação de %s ...", ARCGIS_GEOJSON_URL)
    with httpx.stream("GET", ARCGIS_GEOJSON_URL, follow_redirects=True, timeout=60) as r:
        r.raise_for_status()
        with cache_path.open("wb") as f:
            for chunk in r.iter_bytes():
                f.write(chunk)
    log.info("Dataset salvo em %s", cache_path)


def load_iluminacao_geojson(cache_path: Path = _DEFAULT_CACHE) -> dict:
    """Retorna o GeoJSON de iluminação como dict Python.

    Faz download automático se o cache não existir.
    """
    if not cache_path.exists():
        download_iluminacao(cache_path)
    with cache_path.open(encoding="utf-8") as f:
        return json.load(f)
```

A path `_DEFAULT_CACHE` aponta para `fala-gavea-seguranca/data/iluminacao.geojson` resolvendo de dentro de `infrastructure/iluminacao/`. Verificar a profundidade `.parent` × 5 contra o layout real do projeto.

### Step 2: Criar router FastAPI para iluminação

Criar `fala-gavea-seguranca/src/fala_gavea_seguranca/presentation/api/routers/iluminacao.py`:

```python
from __future__ import annotations

from fastapi import APIRouter, BackgroundTasks, HTTPException, status
from fastapi.responses import JSONResponse

from fala_gavea_seguranca.infrastructure.iluminacao.loader import (
    _DEFAULT_CACHE,
    download_iluminacao,
    load_iluminacao_geojson,
)

router = APIRouter()


@router.get("/geojson")
def get_iluminacao_geojson() -> JSONResponse:
    """Retorna o GeoJSON do dataset de iluminação pública (cache local).

    Se o cache não existir, faz o download automaticamente.
    Retorna 503 se o download falhar.
    """
    try:
        geojson = load_iluminacao_geojson()
        return JSONResponse(content=geojson)
    except Exception as e:
        raise HTTPException(
            status_code=status.HTTP_503_SERVICE_UNAVAILABLE,
            detail=f"Dataset de iluminação não disponível: {e}",
        )


@router.post("/refresh", status_code=status.HTTP_202_ACCEPTED)
def refresh_iluminacao(background_tasks: BackgroundTasks) -> dict:
    """Dispara re-download do dataset em background."""
    background_tasks.add_task(download_iluminacao, _DEFAULT_CACHE)
    return {"message": "Download iniciado em background."}
```

Dois endpoints:
- `GET /iluminacao/geojson` — serve o cache local (download automático se ausente)
- `POST /iluminacao/refresh` — re-download assíncrono (para atualizar dados sem reiniciar o servidor)

### Step 4: Adicionar camada de iluminação ao frontend Leaflet

Em `static/app.js`, adicionar após as constantes no topo:

```javascript
// Illumination layer (lazy-loaded)
let iluminacaoLayer = null;
const iluminacaoLayerGroup = L.layerGroup();

async function loadIluminacao() {
  if (iluminacaoLayer) return;
  try {
    const res = await fetch('/iluminacao/geojson');
    if (!res.ok) return;
    const geojson = await res.json();
    iluminacaoLayer = L.geoJSON(geojson, {
      pointToLayer: (_feat, latlng) =>
        L.circleMarker(latlng, {
          radius: 3,
          color: '#f0c040',
          fillColor: '#f0c040',
          fillOpacity: 0.6,
          weight: 0,
        }),
    });
    iluminacaoLayerGroup.addLayer(iluminacaoLayer);
  } catch (e) {
    console.warn('Camada de iluminação não disponível:', e);
  }
}
```

Depois de criar o tile layer base e antes de `loadReports()`, adicionar o controle de camadas:

```javascript
const baseMaps = {};
const overlayMaps = {
```

## Risks & Mitigations

| Risk | Mitigation |
|---|---|
| Dataset ArcGIS indisponível ou URL mudou | `GET /iluminacao/geojson` retorna 503 com mensagem descritiva; camada simplesmente não aparece no mapa |
| Dataset muito grande (>100k pontos) → resposta lenta | O GeoJSON é servido via `JSONResponse` do cache local (leitura de disco, <100ms); a lentidão de download ocorre apenas no primeiro acesso ou ao "Atualizar" |
| Path de `_DEFAULT_CACHE` errado (profundidade `.parent`) | Verificar no Step 1 — contar a profundidade real de `infrastructure/iluminacao/loader.py` até `fala-gavea-seguranca/` |
| GeoJSON grande causando timeout no browser | Leaflet renderiza GeoJSON de forma síncrona; se >50k features, aplicar subsample no endpoint: `features[:50000]` |

## Review

**P0 — Correctness**
- `load_iluminacao_geojson` faz download automático se cache ausente — garante que `GET /geojson` não retorne 503 na primeira chamada (a menos que o download falhe).
- `POST /refresh` usa `BackgroundTasks` — retorna 202 imediatamente sem bloquear o event loop do uvicorn. Correto para download de arquivo grande.
- Profundidade de `_DEFAULT_CACHE`: `loader.py` está em `src/fala_gavea_seguranca/infrastructure/iluminacao/loader.py`. Cinco `.parent`s: `iluminacao/` → `infrastructure/` → `fala_gavea_seguranca/` → `src/` → `fala-gavea-seguranca/` → raiz. Portanto `Path(__file__).parents[4] / "data" / "iluminacao.geojson"` é mais legível e correto.

**P1 — Security**
- URL hardcoded: aceitável para dataset público sem autenticação.
- Cache em disco em `fala-gavea-seguranca/data/` — gitignored.
- Sem path traversal: `cache_path` é derivado de `__file__`, não de input do usuário.

**P2 — Maintainability**
- `GET /geojson` e `POST /refresh` são independentes — fácil de testar em isolamento.
- Loader é stateless e puro: testável com `tmp_path` sem rede (monkeypatching de `httpx.stream`).
