## Agent Interpretation
The current `page_clusters()` in `fala-gavea/app.py` renders a Plotly scatter plot (colored by `cluster_label`) and a summary table with cluster label, post count, and one example post. The LLM-generated topic label is present in the color legend but is not surfaced clearly as a navigable, text-first view.

The fix: replace the plain summary table with a richer "Posts por Cluster" section. For each cluster, show the LLM-generated topic label as a heading and list all posts in that cluster in an `st.expander`, with a compact table of `text` and `territory_name`. Noise cluster (-1 / "Nao classificado") is shown last. This makes the semantic labeling visible and lets the user read the actual posts per topic without guessing from the scatter plot.

## Steps

### Step 1: Replace cluster summary table with per-cluster expander list
In `fala-gavea/app.py`, inside `page_clusters()`, replace the `st.subheader("Resumo dos clusters")` + summary `st.dataframe` block with a new section:

1. Sort clusters: non-noise clusters first (by post count descending), noise cluster last.
2. For each cluster, render:
   - `st.expander(f"**{cluster_label}** ({n} posts)")` -- bold label + count in title
   - Inside the expander: `st.dataframe` of that cluster's posts with columns `text` and `territory_name`, using `use_container_width=True`
3. Retain the scatter plot above unchanged.

The noise cluster (cluster_id == -1, label "Nao classificado") is included but sorted last; if there are no noise points, no expander is shown for it.

Keep the existing `save_btn` logic (which iterates over `df`) intact -- it reads `df` directly and is unaffected by this display change.

**Implementation sketch:**

```python
st.subheader("Posts por Cluster")

# Sort: non-noise first (by count desc), noise last
cluster_groups = df.groupby("cluster_label")
counts = cluster_groups.size().reset_index(name="n")
noise_label = "Nao classificado"
main = counts[counts["cluster_label"] != noise_label].sort_values("n", ascending=False)
noise = counts[counts["cluster_label"] == noise_label]
ordered = pd.concat([main, noise]).reset_index(drop=True)

for _, row in ordered.iterrows():
    label = row["cluster_label"]
    n = row["n"]
    cluster_posts = df[df["cluster_label"] == label][["text", "territory_name"]].copy()
    cluster_posts.columns = ["Relato", "Territorio"]
    with st.expander(f"{label}  ({n} posts)", expanded=False):
        st.dataframe(cluster_posts, use_container_width=True)
```
